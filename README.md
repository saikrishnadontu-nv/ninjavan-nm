# stock_match

Stock Drift Check for the Control Tower team (warehouse 1A).

- `PRD.md`: what the app does, in plain English
- `backend/`: the small server and the web page (`backend/static/index.html`, `logic.js`)
- `cicd/Dockerfile.backend`, `substrait.yaml`: what Substrait needs to run it
- `sample_exports/`: the sample files used to build and test (not shipped in the upload zip)
- `stock_match_substrait.zip`: ready to upload to Substrait
